# 이번 주 집밥 · 125개 레시피 체험판

압축을 푼 뒤 `weekly.html`을 브라우저에서 여세요. `assets` 폴더는 HTML 옆에 그대로 두어야 음식 사진이 표시됩니다. 별도 설치나 인터넷 연결은 필요하지 않습니다.

- 국/찌개 32개, 메인 32개, 밑반찬 31개, 한 그릇 30개
- 상단 ‘레시피 모아보기’에서 카테고리·요리명·재료로 검색
- 레시피 목록에서 선택한 요리는 별도로 2인/4인 분량 확인 가능
- 주간 식단은 한 상 5회와 한 그릇 2회로 구성하고 같은 주의 메인 메뉴 중복을 피함
- 같은 국은 한 주에 한 번만 추천하고, 된장국·된장찌개나 콩나물국 종류처럼 비슷한 국은 최소 3일 간격으로 배치. 개별 메뉴 교체에도 같은 규칙을 적용
- 국·메인·반찬·밥을 합산한 장보기, 기본양념 기억 기능
- 기본 재료 기억은 같은 브라우저의 로컬 저장소에 보관. 브라우저 데이터 삭제 시 초기화되며 계정 간 동기화는 없음
- 상품과 실제 결제 및 쉐어링크는 아직 연결되지 않음

레시피는 자체 작성한 초안이며 외부 인기 레시피 대조와 실제 조리·시식 검증은 완료하지 않았습니다. 모든 음식 사진은 AI 예시 이미지입니다. 기존 17개 음식 사진의 원본 바이트는 유지하고 새 108개 음식 이미지를 별도로 추가했습니다.

`recipes.json`은 전체 레시피 데이터의 검토용 내보내기 파일입니다. 현재 실행 화면의 데이터는 `weekly.html`에 포함되어 있으며 JSON만 수정해도 자동 반영되는 구조는 아닙니다.

## 검증

Node.js가 있으면 이 폴더에서 `node verify-recipes.cjs`를 실행하세요. 레시피 개수와 중복, 인원별 재료, 식단 구성, 1,000회 식단 생성과 1,400회 개별 교체의 국 중복·간격, 사진 연결 및 이미지 파일을 검증하고 `recipes.json`을 갱신합니다.
